IRONVEIL site (built on the Titan template)
-------------------------------------------
Open the folder in VS Code and open index.html (Live Server works well, double-clicking also works).

Pages:   index.html (home), shop.html, contact.html, register.html
Theme:   assets/css/ironveil.css  <- the only file we changed on top of the template (colors, fonts, layout tweaks)
Images:  assets/images/ironveil/  <- placeholder product art + backgrounds (SVG). Swap in real photos here.

Everything is a mockup: forms send nothing, buttons say "Not for sale", prices are placeholders.
Fonts and icons load from the internet, so you need a connection to see them.
